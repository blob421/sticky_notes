Sticky Notes 
====================

Requirements
--------------------
1. A GTK 3.0 compatible system (Linux)
2. Python 3
3. Python gi libraries for Linux

Description
----------------------
A widget app for taking notes. Useful for reminders, to-do lists or easy access.


Features
----------------------

Toolbar:

1. Create and delete notes (+, ❌).
2. Navigate left or right (⬅️, ➡️).
3. A counter that make navigation intuitive (1 / 1)
3. Lock the widget's position (🔒) (locked by default)

Other features:

1. Undo and redo (ctrl+z, ctrl+y)
2. Picks up where you left off after starting up the program
3. A deletion guard
