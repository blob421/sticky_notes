Sticky Notes 
====================

Requirements
--------------------
1. A GTK 3.0 compatible system
2. Python gi libraries for Linux

Description
----------------------
A widget app for taking notes. Useful for reminders, to-do lists or easy access.


Features
----------------------

You can :

1. Create and delete notes.
2. Navigate left or right.
3. Lock the widget's position

It has a counter that makes navigation intuitive.
It remember where you left
